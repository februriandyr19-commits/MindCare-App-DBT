# MindCare AI & DBT - Prototipe Aplikasi Kesehatan Mental

MindCare AI adalah prototipe aplikasi kesehatan mental interaktif berbasis **AI (NLP)** dan **Terapi Perilaku Dialektis (DBT)** yang dirancang dengan antarmuka empatik dan modern khusus untuk Milenial dan Gen Z.

## 🌟 Fitur Utama
1. **Layar 1: Jurnal Harian (Input Pasif & NLP)** - Dikte suara (*Voice-to-Text*), pemilih *Mood*, dan deteksi otomatis pemicu emosi/krisis.
2. **Layar 2: Dashboard Indikator Afektif** - Grafik tren emosi mingguan SVG interaktif dan penanda emosi dominan (*Overthinking*, *Fatigue*, *Low Mood*).
3. **Layar 3: Modul Interaktif DBT** - Alat pendorong pernapasan *Mindfulness 4-7-8* dengan Web Audio API dan kuis regulasi emosi.
4. **Layar 4: Modul Tanggap Krisis (SOS)** - Panduan *Grounding 5-4-3-2-1* serta panggil cepat hotline kesehatan mental resmi (Kemenkes 119 Ext 8).

## 🛠️ Teknologi yang Digunakan
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (via CDN)**
- **Font Awesome 6 Icons**
- **Web Speech API & Web Audio API**

## 🚀 Deployment
Aplikasi ini bersifat *static web page* (tanpa *build tool*) dan siap di-deploy langsung ke **Cloudflare Pages** atau **GitHub Pages**.
